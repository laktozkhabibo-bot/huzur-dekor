# 🏠 Huzur Dekor — موقع فاخر لشركة ديكورات داخلية

موقع احترافي متعدد اللغات (التركية افتراضياً + الإنجليزية + العربية مع RTL) لشركة **Huzur Dekor**، مع **لوحة تحكم كاملة** لصاحب الموقع يعدّل منها كل شيء (المشاريع، الصور، الخدمات، النصوص، بيانات التواصل، الإعلان العلوي) وتظهر التعديلات على الموقع **فوراً دون إعادة نشر**.

---

## ✨ المزايا

**الموقع**
- الصفحات: الرئيسية، الخدمات `/hizmetler`، المشاريع `/projeler` (فلترة حسب التصنيف)، صفحة لكل مشروع `/projeler/[slug]` مع معرض صور مكبّر، من نحن `/hakkimizda`، التواصل `/iletisim`.
- اللغات: التركية في الجذر `/`، والإنجليزية `/en`، والعربية `/ar` (اتجاه RTL كامل وخط عربي خاص).
- حركات احترافية هادئة:
  - شاشة افتتاحية قصيرة.
  - عنوان يظهر حرفاً حرفاً.
  - صورة مقوّسة تنكشف كالستارة مع Parallax.
  - ختم «معاينة مجانية» دوّار.
  - شريط خدمات متحرك.
  - كشف الصور عند التمرير.
  - قسم «مراحل العمل» بصورة ثابتة تتبدّل مع التمرير.
  - عدّادات متحركة.
  - تمرير ناعم (Lenis).
  - **لا شيء يتحرك عند مرور الماوس**، والماوس عادي.
- أزرار واتساب برسائل جاهزة: عام، ولكل خدمة، ولكل مشروع.
- نموذج «اطلب عرض سعر»: الاسم، الهاتف، البريد (اختياري)، الخدمة، الرسالة. يصل إلى لوحة التحكم.
- SEO كامل:
  - العناوين والوصف لكل لغة.
  - hreflang و canonical.
  - Sitemap و robots.
  - Open Graph، وJSON-LD من نوع HomeAndConstructionBusiness.

**لوحة التحكم** (`/hostpagepass` ← `/hostpage`)
- **المشاريع:** إضافة وتعديل وحذف وترتيب، رفع صور بالسحب والإفلات، وإبراز في الرئيسية أو إخفاء.
- **التصنيفات:** مثل المطابخ ووحدات التلفزيون والصالونات.
- **محتوى الموقع:** الواجهة وصورتاها، الخدمات (ولكل خدمة أيقونة وصورة)، مراحل العمل وصورها، «لماذا نحن»، الأرقام، من نحن، آراء العملاء، قسم طلب العرض، الشعار، SEO.
- **التواصل:** واتساب، الهاتف، البريد، العنوان، ساعات العمل، وروابط إنستغرام وفيسبوك ويوتيوب وتيك توك.
- **الإعلان العلوي:** شريط متحرك يمكن تشغيله وإيقافه.
- **طلبات العروض:** تعرض الرسائل الواردة مع أزرار واتساب واتصال مباشر، وعدّاد لغير المقروء.
- **تغيير كلمة المرور.**
- **تعدد اللغات:** كل نص يُكتب بثلاث لغات، مع زر لتبديل لغة التحرير.
- **الحفظ:**
  - تحذير عند الخروج دون حفظ.
  - اختصار `Ctrl + S`.
  - يُحفظ كل شيء في معاملة واحدة.

**الأمان**
- كلمة المرور مخزّنة مشفّرة بـ bcrypt في قاعدة البيانات، ولا توجد في كود الواجهة.
- الجلسة في كوكي `httpOnly` و`sameSite=strict`، والـ Middleware يحمي `/hostpage` و`/api/admin`.
- يُقفل الدخول 15 دقيقة بعد 5 محاولات خاطئة، ويعمل هذا القفل حتى على Vercel.
- تغيير كلمة المرور يُغلق الجلسات على كل الأجهزة الأخرى.

## 💻 التثبيت والتشغيل محلياً

```bash
# 1) تثبيت الحزم
npm install

# 2) إنشاء ملف البيئة ثم تعبئته (انظر الجدول أدناه)
cp .env.example .env

# 3) إنشاء جداول قاعدة البيانات
npx prisma migrate deploy

# 4) تعبئة البيانات الأولية (6 مشاريع، 3 تصنيفات، كل النصوص، كلمة مرور اللوحة)
npm run db:seed

# 5) التشغيل
npm run dev
```

الروابط:
- الموقع: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/hostpagepass`

> محلياً، إن لم تضع `BLOB_READ_WRITE_TOKEN` تُحفظ الصور المرفوعة في `public/uploads`، وهذا للتجربة مع `npm run dev` فقط. على Vercel يجب ربط Vercel Blob.

## 🔐 متغيرات البيئة (.env)

| المتغير | إلزامي | الوصف |
|---|---|---|
| `DATABASE_URL` | ✅ | رابط PostgreSQL، ويُفضّل الرابط الـ Pooled. |
| `DIRECT_URL` | ✅ | الرابط المباشر غير الـ Pooled، ويستخدمه `prisma migrate`. إن لم يكن لديك Pooler فضع نفس القيمة. |
| `SESSION_SECRET` | ✅ | نص عشوائي من 32 حرفاً على الأقل. يمكن إنشاؤه بالأمر `openssl rand -base64 48` |
| `HOST_INITIAL_PASSWORD` | اختياري | كلمة المرور الأولى للوحة، والافتراضية `123456789`. تُستخدم مرة واحدة فقط. |
| `BLOB_READ_WRITE_TOKEN` | ✅ على Vercel | يُضاف تلقائياً عند ربط Blob Store. |
| `NEXT_PUBLIC_SITE_URL` | ✅ | رابط الموقع النهائي، مثل `https://www.huzurdekor.com` |

> ⚠️ لا ترفع ملف `.env` إلى GitHub ولا تشاركه مع أحد، فهو مستثنى في `.gitignore`.

## 🔑 كلمة مرور لوحة التحكم

- **كلمة المرور الافتراضية:** `123456789`
- **الدخول:** من `/hostpagepass`.
- **التغيير (يُنصح به فوراً):**
  1. من اللوحة اختر **«Şifre Değiştir»**.
  2. أدخل كلمة المرور الحالية.
  3. أدخل كلمة المرور الجديدة مرتين (8 أحرف على الأقل).
- **إن نسيتها:** نفّذ هذا الأمر من جهازك بنفس `DATABASE_URL` الخاص بالموقع:
  ```bash
  npm run host:password -- "كلمة-المرور-الجديدة"
  ```

## 🚀 النشر على Vercel

1. **ارفع المشروع إلى GitHub**، بدون `.env` وبدون `node_modules`.
2. **أنشئ المشروع:** ادخل [vercel.com/new](https://vercel.com/new) واختر المستودع. لا تغيّر أمر البناء، فسكربت `vercel-build` ينفّذ بالترتيب:
   - `prisma generate`
   - `prisma migrate deploy`
   - `prisma db seed` (يملأ القاعدة إن كانت فارغة فقط)
   - `next build`
3. **قاعدة البيانات:**
   1. من Storage اختر Create Database.
   2. اختر **Neon** أو **Prisma Postgres** ثم Connect.
   3. تأكد من وجود `DATABASE_URL` و`DIRECT_URL`. في Neon انسخ قيمة `DATABASE_URL_UNPOOLED` إلى متغير جديد اسمه `DIRECT_URL`.
4. **الصور:** من Storage اختر Create ثم **Blob** ثم Connect.
5. **المتغيرات:** من Settings ثم Environment Variables أضف:
   - `SESSION_SECRET`
   - `NEXT_PUBLIC_SITE_URL`
   - `HOST_INITIAL_PASSWORD` (اختياري)
6. **انشر:** اضغط Deploy، ثم افتح `/hostpagepass` وسجّل الدخول بـ `123456789`، وغيّر كلمة المرور فوراً.
7. **النطاق الخاص:**
   1. من Settings ثم Domains أضف نطاقك.
   2. حدّث `NEXT_PUBLIC_SITE_URL`.
   3. أعد النشر مرة واحدة.

## ⚡ كيف تظهر التعديلات فوراً؟
- صفحات الموقع مولّدة مسبقاً، لذلك هي سريعة جداً.
- البيانات مخزّنة مع وسوم Cache.
- عند الضغط على **«Değişiklikleri Kaydet»**:
  1. يُحفظ كل شيء في قاعدة البيانات.
  2. يُستدعى `revalidateTag` و`revalidatePath`.
  3. تتحدّث الصفحات مع الزيارة التالية مباشرة، دون أي Build أو Deploy.
- المشاريع الجديدة تحصل على صفحتها تلقائياً.
